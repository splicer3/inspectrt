# Security policy

Report a suspected vulnerability privately to
`matteo.di.iorio@icloud.com`. Do not open a public issue for an undisclosed
vulnerability.

Include the affected InspectRT version or source commit, environment,
reproduction steps, expected security impact and a suggested mitigation when
available. Do not send MVTec data, pretrained weights, private run bundles,
private paths, credentials, tokens or other secrets. Coordinate disclosure
before publishing details that could expose users.

Security fixes target the latest published release line. No response-time or
remediation SLA is promised. Security support does not imply industrial
safety, production readiness or hard-real-time certification.

GitHub private vulnerability reporting is a separate repository setting and
is not implied by this file.
